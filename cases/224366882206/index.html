고객이 요청한 문제

콘센트는 매일 사용하는 전기 설비이지만 오래 사용하다 보면 내부 접점이 마모되거나 외부가 파손되어 감전 위험이나 접촉 불량이 생기는 경우가 생각보다 많습니다. 이번 현장도 딱 그런 상황이었습니다. 찌릿한 위험을 없애고 안전하게 사용합니다. 생활하면서 불편했던 작은 부분부터 문 방향 변경, 가구 리폼, 각종 설치 작업까지 기존 콘센트는 사용한 지 오래된 상태였고, 고객님께서도 감전이 걱정되어 더 이상 사용하기 어렵다고 말씀하셨습니다.

  • 외부 커버가 일부 파손
  • 콘센트가 흔들리는 상태
  • 사용할 때마다 찌릿한 느낌 발생

작업 과정 · 작업 방법

  1. STEP 1새 제품 확인

    이번에 설치한 제품은 신형 2구 콘센트입니다. 작업 전 먼저 제품 상태부터 확인합니다. 설치 전에 제품 상태를 확인해야 불량 제품으로 인한 재작업을 막을 수 있습니다.

    • 외관 파손 여부
    • 내부 단자 확인
    • 구성품 이상 유무 체크

  2. STEP 2철거 작업

    기존 콘센트를 먼저 철거합니다.

    • 차단기 전원 차단
    • 기존 콘센트 분리
    • 배선 상태 확인

  3. STEP 3배선 손상 확인

    오래된 콘센트는 내부 배선까지 손상되어 있는 경우도 있어 배선 피복과 단자 상태를 꼼꼼하게 확인합니다. 새 제품을 바로 설치하지 않고 한 번 더 확인합니다. 이 과정이 제대로 되지 않으면 콘센트가 흔들리거나 접촉 불량이 발생할 수 있습니다.

    • 배선 연결 상태 확인
    • 고정 브라켓 확인
    • 수평 상태 확인

  4. STEP 4본 설치 진행

    이제 본격적으로 설치를 진행합니다. 그리고 가장 중요한 단계 전원을 다시 투입한 후 콘센트가 정상적으로 작동하는지 꼼꼼하게 확인합니다.

    • 배선 연결
    • 콘센트 고정
    • 전면 커버 조립
