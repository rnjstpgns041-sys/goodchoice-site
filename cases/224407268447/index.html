고객이 요청한 문제

빌트인 식기세척기는 싱크대 하부장 한 칸을 사용하여 설치하는 경우가 많습니다. 그런데 식기세척기를 더 이상 사용하지 않게 되어 철거하고 나면 그 자리가 그대로 비어 있어 주방이 허전해 보이거나 수납공간을 활용하지 못하는 문제가 생길 수 있습니다. 이번 현장 역시 기존 싱크대 하부장에 설치되어 있던 빌트인 식기세척기를 철거한 뒤 비어 있는 공간에 맞춰 새로운 하부장을 제작해 달라는 의뢰를 주셨습니다. 빌트인 식기세척기 철거 후 비어 있던 자리에 하부장을 제작해 깔끔한 수납공간으로 바꿨습니다.

  • 식기세척기를 더 이상 사용하지 않음
  • 철거 후 공간 활용이 필요함
  • 기존 싱크대와 어울리는 하부장이 필요함

시공 전 사진

작업 과정 · 작업 방법

  1. STEP 1식기세척기 철거

    먼저 기존에 설치되어 있던 빌트인 식기세척기를 철거합니다. 제품을 무리하게 당겨 빼내면 주변 싱크대나 바닥에 손상이 발생할 수 있기 때문에 연결 상태와 고정 부분을 확인한 뒤 조심스럽게 제품을 분리합니다. 철거가 끝난 뒤에는 제품이 들어가 있던 내부 공간도 함께 확인합니다.

    • 전원 연결 확인
    • 급수 및 배수라인 분리
    • 제품 고정부 확인
    • 식기세척기 안전하게 탈거

  2. STEP 2철거 후 공간 확인

    식기세척기를 빼내고 나니 사진처럼 싱크대 아래쪽에 큰 공간이 그대로 남았습니다. 이 상태로 사용하면 외관상 보기에도 좋지 않고 수납공간으로 활용하기에도 불편할 수밖에 없습니다. 그래서 하부장을 제작하기 전 필요한 치수를 꼼꼼하게 확인하였습니다.

    • 내부 폭과 높이 측정
    • 기존 싱크대 깊이 확인
    • 주변 문짝과 간격 확인
    • 바닥 및 상판 상태 확인

  3. STEP 3하부장 맞춤 제작

    확인한 치수를 기준으로 새로운 하부장을 제작합니다. 사진처럼 먼저 하부장의 몸통을 제작하고 기존 주방과 최대한 자연스럽게 이어질 수 있도록 전체 크기와 형태를 맞춰줍니다. 특히 이번 현장은 화이트 계열의 싱크대였기 때문에 새롭게 제작하는 장 역시 전체 주방 분위기와 어울릴 수 있도록 깔끔한 화이트 계열로 맞췄습니다.

    • 공간에 맞는 장 크기 제작
    • 측판 및 내부 구조 조립
    • 전면 문짝 사이즈 확인
    • 기존 싱크대 높이에 맞춰 제작

  4. STEP 4문짝 제작 및 조립

    하부장 몸통을 완성한 뒤에는 전면에 들어갈 문짝을 준비합니다. 식기세척기가 있던 자리라고 해서 아무 문짝이나 설치하면 기존 싱크대와 높이나 간격이 달라져 새로 만든 부분만 눈에 띌 수 있습니다. 그래서 주변 하부장 문짝과 라인이 최대한 자연스럽게 이어지도록 맞춰주는 것이 중요합니다. 현장에서 여러 번 확인하면서 문짝 위치를 세밀하게 조정합니다.

    • 문짝 크기 맞춤
    • 경첩 위치 가공
    • 문짝 간격 조절
    • 열고 닫히는 상태 확인

  5. STEP 5하부장 설치

    제작을 마친 하부장을 기존 식기세척기가 있던 공간에 맞춰 설치합니다. 이때 단순히 장을 밀어 넣는 것이 아니라 기존 싱크대와의 간격과 앞쪽 문짝 라인을 확인하면서 위치를 잡아줍니다. 문짝까지 설치한 후에는 실제로 여러 번 열고 닫아보면서 주변 문짝과 간섭이 없는지도 확인하였습니다.

    • 좌우 간격 확인
    • 상판 하부 간섭 확인
    • 하부장 수평 조정
    • 기존 싱크대와 라인 맞춤

  • 비어 있던 공간이 사라짐
  • 주방 수납공간 추가 확보
  • 기존 싱크대와 자연스러운 연결
  • 전체적으로 깔끔해진 주방 외관
