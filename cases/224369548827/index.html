고객이 요청한 문제

세탁실은 세탁기와 건조기, 보일러, 수납장까지 함께 있는 경우가 많아 공간이 넉넉하지 않은 구조가 많습니다. 이번 현장 역시 세탁실 문이 안쪽으로 열리는 구조였습니다. 문을 열면 세탁기와 바로 간섭이 생기고, 안으로 들어갈 공간도 좁아 빨래를 넣거나 꺼낼 때마다 불편함이 반복되고 있었습니다. 고객님께서는 문을 바깥쪽으로 열리게 변경하여 세탁실을 더 넓게 사용할 수 있도록 의뢰해 주셨습니다. 문 하나 바꿨을 뿐인데 생활이 훨씬 편해졌습니다.

작업 과정 · 작업 방법

  1. STEP 1기존 상태 확인

    먼저 현재 문틀과 경첩 위치를 확인합니다. 기존에는 문이 세탁실 안쪽으로 열리는 구조라 출입 공간이 많이 제한되고 있었습니다.

    • 문 개폐 방향 확인
    • 문틀 상태 점검
    • 손잡이 및 잠금장치 확인

  2. STEP 2문 철거 작업

    문을 안전하게 분리한 뒤 기존 경첩과 손잡이를 모두 탈거합니다. 무리하게 작업하면 문짝이나 문틀이 손상될 수 있기 때문에 하나씩 순서대로 조심스럽게 분해를 진행합니다.

  3. STEP 3방향 변경 가공

    이번 작업의 핵심입니다. 문이 반대 방향으로 열리도록 기존 자국은 퍼티 작업으로 메우고 표면을 깔끔하게 정리합니다. 현장 상황에 맞춰 문이 자연스럽게 닫히도록 세밀하게 가공을 진행했습니다.

    • 경첩 위치 변경
    • 손잡이 위치 변경
    • 걸쇠 및 타공 가공

  4. STEP 4재설치 및 조정

    가공이 끝난 문을 새로운 방향으로 설치합니다. 문이 걸리거나 자동으로 열리는 현상이 없도록 여러 번 열고 닫으며 미세 조정을 반복했습니다.

    • 문 수평 조정
    • 경첩 고정
    • 문틈 간격 확인
    • 손잡이 작동 테스트

  • 문이 주방 방향으로 열려
