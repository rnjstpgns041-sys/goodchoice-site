고객이 요청한 문제

붙박이장 슬라이딩 도어는 문 자체의 크기와 무게가 상당하기 때문에 상부와 하부의 롤러가 제대로 움직여야 부드럽게 열고 닫을 수 있습니다. 그런데 어느 날 갑자기 문이 뻑뻑해지거나 중간에서 걸리고 예전처럼 움직이지 않는다면 슬라이딩 도어의 롤러 부분을 확인해 볼 필요가 있습니다. 이번 현장도 바로 그런 상황이었습니다. 붙박이장 슬라이딩 도어 고장 롤러 베어링을 다시 살려 부드럽게 움직이도록 수리했습니다. 고객님께서 사용하시던 붙박이장은 대형 슬라이딩 도어 방식이었습니다.

  • 슬라이딩 도어 움직임 불량
  • 문을 열고 닫을 때 걸림 발생
  • 롤러가 레일을 부드럽게 이동하지 못함

시공 전 사진

작업 과정 · 작업 방법

  1. STEP 1문짝 분리 & 상태 확인

    붙박이장 문은 일반 방문보다 크고 무겁습니다. 무리하게 들어내면 문짝이나 프레임뿐만 아니라 바닥과 주변 가구까지 손상될 수 있습니다. 그래서 문을 안전하게 분리한 후 후면의 롤러 구조를 확인했습니다. 롤러 베어링 내부에 들어가는 볼 일부가 정상적인 위치에서 빠지면서 베어링의 움직임이 원활하지 않은 상태였습니다.

  2. STEP 2롤러 베어링 점검

    슬라이딩 도어에서 롤러는 문을 움직이는 핵심 부품입니다. 특히 베어링 내부의 볼이 정상적인 위치에서 회전해야 무거운 문도 부드럽게 이동합니다. 단순히 문짝을 다시 끼우는 것으로는 해결되지 않는 상태였기 때문에 베어링 자체를 먼저 복원했습니다.

    • 롤러 베어링 상태 확인
    • 빠져 있는 내부 볼 확인
    • 손상 여부 점검

  3. STEP 3베어링 볼 재배치 작업

    이번 작업의 핵심입니다. 베어링 내부에서 빠져 있던 볼을 하나씩 정상 위치에 다시 배치합니다. 볼의 위치가 맞지 않으면 롤러가 원활하게 회전하지 못하고 무거운 문을 움직일 때 계속 걸림이 발생할 수 있습니다. 다시 조립한 뒤에는 손으로 롤러를 움직여 보면서 회전 상태를 확인했습니다.

    • 내부 볼 위치 확인
    • 빠진 볼 재배치
    • 베어링 회전 상태 확인
    • 롤러 움직임 점검

  4. STEP 4슬라이딩 도어 재설치

    롤러 수리를 마친 뒤 분리했던 붙박이장 문을 다시 설치합니다. 여기서도 중요한 부분은 문만 걸어놓고 끝내는 것이 아니라 롤러와 레일의 위치를 정확하게 맞추는 것입니다. 문짝이 크고 무거운 만큼 조금만 위치가 틀어져도 움직임이 달라질 수 있습니다.

    • 상부 롤러 위치 확인
    • 레일과 롤러 맞춤
    • 문짝 수평 상태 점검
    • 좌우 이동 상태 확인
